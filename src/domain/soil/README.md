# Caracterização do solo

O perfil distingue valores conhecidos de valores desconhecidos. Um pH só é aceite como medição numérica explícita; a aparência ou a cor do solo não são utilizadas como substituto de um teste.

A validação sintáctica não confirma a qualidade agronómica da medição. A origem, o método e a data devem ser preservados sempre que disponíveis.

## Atributos registados no espaço climático

O formulário permite registar textura, humidade observada, drenagem, fertilidade percebida e matéria orgânica percebida, além do pH medido. Os campos categóricos preservam explicitamente o estado desconhecido.

Estes atributos são contexto declarado pelo utilizador, não medições laboratoriais automáticas. Na versão actual, apenas o pH é comparado com intervalos de referência da cultura. Textura, drenagem, fertilidade e matéria orgânica não geram pontuações ou recomendações porque o catálogo ainda não contém referências locais validadas para esses factores.

O perfil é mantido no estado da interface durante a análise; não é persistido numa conta ou base de dados.
